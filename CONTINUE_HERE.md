# Plan: kayoutf — R Package for Kayou Transformers Card Database

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Create an R package `kayoutf` that provides a comprehensive, queryable database of all Kayou Transformers trading cards. Data stored as Parquet files, queried via DuckDB, with convenience functions returning tibbles.

## Database Schema

### Table: `sets`
| Column | Type | Description |
|--------|------|-------------|
| set_code | VARCHAR (PK) | e.g. "TFEU01", "TF01", "TF40Y" |
| set_name_en | VARCHAR | English name |
| set_name_zh | VARCHAR | Chinese name |
| product_line | VARCHAR | e.g. "Cybertron Leader Edition", "Energon Universe" |
| release_year | INTEGER | |
| theme | VARCHAR | e.g. "G1", "Rise of the Beasts", "Energon Universe Comics" |
| total_cards | INTEGER | Total unique cards in set |

### Table: `products` (pack types within a set)
| Column | Type | Description |
|--------|------|-------------|
| product_id | VARCHAR (PK) | e.g. "TFEU01-super", "TFEU01-elite" |
| set_code | VARCHAR (FK) | |
| product_name_en | VARCHAR | e.g. "Super Quantum Pack" |
| product_name_zh | VARCHAR | e.g. "超量包" |
| cards_per_pack | INTEGER | |
| packs_per_box | INTEGER | |
| total_cards | INTEGER | Cards available in this product |
| barcode | VARCHAR | EAN if known |

### Table: `rarities` (rarity definitions per set)
| Column | Type | Description |
|--------|------|-------------|
| rarity_id | VARCHAR (PK) | e.g. "TFEU01-XR", "TF01-SSR" |
| set_code | VARCHAR (FK) | |
| rarity_code | VARCHAR | e.g. "XR", "SSR", "BP" |
| rarity_name_en | VARCHAR | English name |
| rarity_name_zh | VARCHAR | Chinese name |
| card_count | INTEGER | Number of cards at this rarity |
| sort_order | INTEGER | For ordering (highest rarity = lowest number) |
| notes | VARCHAR | e.g. "Limited to 380 copies" |

### Table: `cards`
| Column | Type | Description |
|--------|------|-------------|
| card_id | VARCHAR (PK) | e.g. "TFEU01-SR-001" |
| set_code | VARCHAR (FK) | |
| rarity_code | VARCHAR | |
| card_number | VARCHAR | Number within rarity, e.g. "001" |
| card_name_en | VARCHAR | English card/character name |
| card_name_zh | VARCHAR | Chinese card name |
| character_name | VARCHAR | Canonical character name |
| faction | VARCHAR | "Autobot", "Decepticon", "Other" |
| card_type | VARCHAR | e.g. "character", "scene", "cover_variant", "lenticular", "die_cut" |
| is_parallel | BOOLEAN | Whether this is a parallel/variant of another card |
| parallel_of | VARCHAR | card_id of the base version, if parallel |
| product_exclusive | VARCHAR | product_id if exclusive to a pack type |
| print_run | INTEGER | If limited, the print run number |
| image_url | VARCHAR | URL to card image if available |

### Table: `characters` (lookup/reference)
| Column | Type | Description |
|--------|------|-------------|
| character_name | VARCHAR (PK) | Canonical English name |
| character_name_zh | VARCHAR | Chinese name |
| faction | VARCHAR | Primary faction |
| alt_mode | VARCHAR | e.g. "Truck", "Jet", "Cassette" |

## Key R Dependencies

- `DBI`, `duckdb` — core database engine
- `tibble` — return type for convenience functions
- `arrow` — Parquet file creation in data-raw scripts (Suggests)
- `dplyr`, `dbplyr` — for lazy table access (Suggests)

## API Design (user-facing functions)

```r
# Get DuckDB connection (power users)
kt_connection()

# Get lazy dbplyr table (power users)
kt_tbl("cards")

# Convenience tibble accessors
kt_cards(set = NULL, rarity = NULL, character = NULL, faction = NULL)
kt_sets()
kt_rarities(set = NULL)
kt_characters(faction = NULL)
kt_products(set = NULL)
```

All `kt_*` functions use the `kt_` prefix (short for "kayou transformers").

## Implementation Steps

### Step 1: Scaffold the R package
- Create DESCRIPTION, NAMESPACE, .Rbuildignore, .gitignore, LICENSE
- Create R/ directory with package skeleton files
- Set up roxygen2 documentation framework

### Step 2: Build the data pipeline (`data-raw/`)
- Create `01_sets.R` — hardcoded set metadata for all ~9 known sets
- Create `02_rarities.R` — rarity tier definitions per set
- Create card data scripts per set, starting with TFEU01 (most complete data from booklets)
- Create `04_characters.R` — character reference table
- Create `05_build_parquet.R` — reads all data-raw scripts, writes Parquet to inst/extdata/

### Step 3: Populate TFEU01 data
- Extract card details from booklet scans (character names from artwork, card counts from Chinese text)
- Cross-reference with web sources (TFW2005, TCDB, eBay listings)
- Fill in cards table for both Super Quantum and Elite pack

### Step 4: Populate other sets (skeleton data)
- Add set/rarity metadata for TF01, TF02, TF03, TFH01, TFO01, TF40Y
- Add whatever card-level data is available from web research
- Mark incomplete data clearly (NA values for unknown fields)

### Step 5: Implement R functions
- `R/zzz.R` — package environment, connection lifecycle
- `R/connection.R` — `kt_connection()` with DuckDB singleton
- `R/data-access.R` — all `kt_*` convenience functions
- `R/kayoutf-package.R` — package-level documentation

### Step 6: Tests
- Test DuckDB connection opens and closes
- Test each accessor function returns correct structure
- Test filtering parameters work

### Step 7: Build and verify
- Run `data-raw/05_build_parquet.R` to generate Parquet files
- Run `devtools::check()` to verify package integrity
- Verify DuckDB can query all Parquet files correctly

## Data Size Estimate

~1,000-1,200 cards across all sets × ~15 columns = well under 1 MB as Parquet. Safe to ship in `inst/extdata/` without download-on-first-use complexity. Can add image data or expand later.

## Key Data Sources

- **TCDB**: tcdb.com — partial checklists for TF01-TF03
- **TFW2005 forums**: tfw2005.com/boards — detailed TF40Y rarity breakdowns
- **Trading Card Archives**: tradingcardarchives.com — TF01/TF02 reviews
- **Seibertron**: seibertron.com — TFO01 card images
- **eBay listings**: Card numbering visible in lot listings (e.g. TFH01-SSR-014/018)
- **Booklet PDFs**: In this repo under `TFEU01/` — most complete source for TFEU01
